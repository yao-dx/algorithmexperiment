# 0-1 背包问题算法实验报告

## 一、算法原理详解

### 1. 蛮力法（穷举法）

**核心思路**：枚举所有可能的物品组合，每个物品有选或不选两种状态，共 2^n 种组合。

**执行流程**：
1. 遍历 0 到 2^n - 1 的所有整数
2. 将整数转换为二进制表示（0=不选，1=选）
3. 计算当前组合的总重量和总价值
4. 若满足容量约束且价值更大，更新最优解

**时间复杂度**：O(2^n) - 指数级
**空间复杂度**：O(n)

**局限性**：n > 20 时运行时间急剧增长，无法处理大规模数据。

---

### 2. 动态规划法

**核心思路**：将问题分解为子问题，利用子问题的最优解推导原问题的最优解。

**状态转移方程**：
dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])

**优化方案**：使用一维滚动数组，空间复杂度优化为 O(C)

**时间复杂度**：O(n × C) - 多项式级
**空间复杂度**：O(C)（优化后）

**优势**：可以处理较大规模的数据。

---

### 3. 贪心法（近似算法）

**核心思路**：按单位重量价值（v/w）从高到低排序，依次选取物品。

**执行流程**：
1. 计算每个物品的单位价值
2. 按单位价值降序排序
3. 依次选取物品直至背包装满

**时间复杂度**：O(n log n) - 主要开销在排序
**空间复杂度**：O(n)

**贪心法的局限性**：
- 0-1背包问题中贪心无法保证全局最优解
- 原因：物品不可分割，局部最优选择可能导致错过更好的组合

---

### 4. 回溯法（带剪枝优化）

**核心思路**：深度优先搜索枚举组合，通过剪枝策略提前排除无效分支。

**剪枝策略**：
1. 容量剪枝：当前重量+物品重量>容量时不选
2. 界值剪枝：当前价值+剩余最大可能价值<当前最优时停止搜索

**时间复杂度**：O(2^n)（最坏情况），实际因剪枝更快
**空间复杂度**：O(n)

**局限性**：n > 25 时运行时间急剧增长。

---

## 二、样例演算（容量=10, w=[2,2,6,5,4], v=[6,3,5,4,6]）

**物品数据**：
物品1: 重量2, 价值6 → 单位价值3.0
物品2: 重量2, 价值3 → 单位价值1.5
物品3: 重量6, 价值5 → 单位价值0.83
物品4: 重量5, 价值4 → 单位价值0.8
物品5: 重量4, 价值6 → 单位价值1.5

**蛮力法**：遍历32种组合，最优解选物品1,2,5，总价值15

**动态规划**：dp[5][10] = 15

**贪心法**：按单位价值排序选物品1,2,5（或1,5），可能得到15或12

**回溯法**：通过剪枝搜索，最优解15

## 三、算法时间复杂度对比分析

### 理论复杂度对比

| 算法 | 时间复杂度 | 增长趋势 | 最大可处理规模 |
|------|-----------|---------|--------------|
| 蛮力法 | O(2^n) | 指数增长 | n ≈ 20 |
| 动态规划 | O(n×C) | 线性增长（对n） | n ≈ 100000 |
| 贪心法 | O(n log n) | 对数增长 | 无限制 |
| 回溯法 | O(2^n) | 指数增长 | n ≈ 25 |

### 实际性能对比分析

**实验结果规律**：

1. **蛮力法**：
   - n=10: ~0ms
   - n=15: ~4ms
   - n=20: ~88ms
   - n=25: >1秒（跳过）
   - 符合 O(2^n) 指数增长规律

2. **动态规划**：
   - n=1000: ~6ms
   - n=10000: ~42ms
   - n=40000: ~175ms
   - 增长趋势接近线性，符合 O(n×C)

3. **贪心法**：
   - n=1000: ~1ms
   - n=10000: ~32ms
   - n=80000: ~1585ms
   - 增长缓慢，符合 O(n log n)

4. **回溯法**：
   - n=10: ~0ms
   - n=20: ~0ms（剪枝效果好）
   - n=25: ~100ms
   - 剪枝优化显著提升性能

### 结论

1. **精确解算法**：动态规划是处理大规模数据的最佳选择
2. **近似解算法**：贪心法速度最快，但无法保证最优解
3. **小规模数据**：蛮力法和回溯法均可使用
4. **理论与实际**：实际运行时间符合理论复杂度趋势

## 八、测试结果汇总

### 算法性能对比表（C=10000）

| n | 蛮力法(ms) | 动态规划(ms) | 贪心法(ms) | 回溯法(ms) |
|---|-----------|-------------|-----------|-----------|
| 10 | 0 | 0 | 0 | 0 |
| 20 | 88 | 0 | 0 | 0 |
| 1000 | 超时 | 6 | 1 | 超时 |
| 10000 | 超时 | 42 | 32 | 超时 |
| 40000 | 超时 | 175 | 424 | 超时 |
| 80000 | 超时 | 397 | 1585 | 超时 |

### 结论分析

1. **时间复杂度验证**：实际运行时间与理论复杂度一致
2. **算法选择建议**：
   - 小规模数据（n<20）：任意算法均可
   - 中等规模（20<n<10000）：动态规划或贪心法
   - 大规模数据（n>10000）：动态规划（精确解）或贪心法（近似解）
3. **空间复杂度**：动态规划对内存要求较高，需注意优化
